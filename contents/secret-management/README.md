# Secret Management

These projects provide Kubernetes integrations for secret storage. Follow each project’s current installation documentation and pin chart/image versions in production.

1. [External Secrets Operator](https://external-secrets.io/)
2. [Secrets Store CSI Driver](https://secrets-store-csi-driver.sigs.k8s.io/)
3. [Sealed Secrets](https://sealed-secrets.netlify.app/)
4. [Vault Secrets Operator](https://developer.hashicorp.com/vault/docs/platform/k8s/vso)
5. [1Password Connect Kubernetes Operator](https://github.com/1Password/onepassword-operator)

No example manifests are present in this directory, so no kind deployment was claimed for these integrations.
