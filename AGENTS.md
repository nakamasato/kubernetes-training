# Repository instructions

## Language

Always use English. Write documentation, code comments, diagram labels, commit messages, and GitHub issue and pull request titles and descriptions in English. Do not switch the language of repository content based on the language used in the conversation.

## Git worktrees

Before editing files, create a new Git worktree from the latest `origin/main` unless already working in a worktree. Do not edit the main checkout by switching its branch. Apply this rule to every repository you modify.

## Documentation and diagrams

Preserve component-level implementation explanations, construction paths, usage walkthroughs, and examples when updating documentation. Update obsolete details in place; do not replace detailed sections with summaries. Preserve the established structure and layout of existing SVG diagrams unless a redesign is explicitly requested.
